# Python mashqlari

Python asoslarini o‘rganish uchun o‘zbek tilidagi kichik mashqlar va yechimlar.

## Fayllar

- `main.py`, `main2.py`–`main12.py` — ro‘yxatlar, satrlar, sikllar, shartlar va algoritmlar bo‘yicha mashqlar.
- `amalyot2.py` — amaliy mashqlar to‘plami.

## Ishga tushirish

Python 3 o‘rnatilgan bo‘lishi kerak. Kerakli faylni terminaldan ishga tushiring:

```bash
python3 main.py
```

Boshqa mashqni bajarish uchun `main.py` o‘rniga kerakli fayl nomini yozing.

VS Code uchun workspace sozlamalari `.vscode/` ichida. Ular Python ishga tushirishni va yashil-qora rang sxemasini sozlaydi.
